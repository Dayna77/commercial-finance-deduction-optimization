Module B · Process Control

Internal Control & Dual-Line DOA Authorization Matrix

Deploying "Three Control Locks" across the lifecycle and empowering precision via a Sales & Finance dual-DOA matrix.

01

Source Lock

Mandatory Promo ID + 4-element check (Customer, Date, SKU, Budget) with automated system warning against duplicate creation.

02

Finance Lock

Hard ceiling enforcement on accruals (Accrual Ceiling). Over-budget claims are blocked automatically.

03

Settlement Lock

Single-use closure per deduction. The system automatically closes the associated Promo ID post-settlement to prevent re-use.
